# Open Agentic Swarm Security Engineering

Interactive article on keeping swarms of parallel LLM agents in scope: a swarm control UX mockup, a deployment architecture, an internal threat model and ideas for controls. English, Spanish and Chinese.

Read it: https://franciscocarloserra.github.io/open-swarm-security/

Discussion: https://news.ycombinator.com/item?id=50064785 and https://x.com/francarloerra/status/2109798460140458101

To open it locally, open `index.html` in a browser. It's plain HTML and JS with no build step.

- `index.html` the article
- `src/` sections, styles and texts (`src/i18n/en.js` base English, `src/i18n/edits.js` the final texts per language)
- `img/` screenshots
- `todo/` placeholders for the reference implementation and the experiment results

No warranties of any kind, use at your own risk.
